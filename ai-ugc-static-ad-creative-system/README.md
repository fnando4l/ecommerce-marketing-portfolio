# AI UGC + Static Ad Creative System

A React portfolio dashboard that shows how AI can support ecommerce ad creative strategy across competitor research, UGC scripts, static ad concepts, product angles, and creative testing.

This project is built for digital marketing coordinator, UGC creative strategist assistant, paid social assistant, brand coordinator, and ecommerce marketing roles.

## What This Shows

- AI-assisted competitor research
- UGC hook and script writing
- Static ad concept development
- Product angle mapping
- Creative testing planning
- Direct-response messaging
- Ecommerce creative strategy

## Tech Stack

- React
- JavaScript
- Vite
- CSS
