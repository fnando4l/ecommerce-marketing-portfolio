## Repo Structure

The root repo is `output/projects/`. Each project folder follows the same kind of structure as Fernand's older React/Vite/Tailwind GitHub projects:

- `.gitignore`
- `README.md`
- `docs/`
- `public/`
- `src/`
- `index.html`
- `package.json`
- `vite.config.js`
- `tailwind.config.js`
- `postcss.config.js`
- `eslint.config.js`

`package-lock.json` is intentionally not hand-written. It should be generated after running `npm install` from the root repo.
