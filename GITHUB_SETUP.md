# GitHub Setup

This folder is ready to become one GitHub repository with three project folders.

Published repo:
`https://github.com/fnando4l/ecommerce-marketing-portfolio`

## Recommended GitHub Repo Name

`ecommerce-marketing-portfolio`

## Manual Push Steps

Run these from the root folder:

`output/projects/`

```bash
git init
git add .
git commit -m "Initial ecommerce marketing portfolio"
git branch -M main
git remote add origin https://github.com/fnando4l/ecommerce-marketing-portfolio.git
git push -u origin main
```

If you use a different repo name, replace `ecommerce-marketing-portfolio` in the remote URL.

## After Upload

Add this GitHub link to the resume project section:

- `github.com/fnando4l/ecommerce-marketing-portfolio`
