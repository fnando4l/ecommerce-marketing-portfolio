# Google Ads Campaign Planner

A React tool that helps plan an ecommerce Google Ads campaign from product and budget inputs.

The user enters a product, monthly budget, average order value, target CPA, and campaign goal. The app generates budget split, KPI targets, keyword groups, ad copy ideas, and landing page priorities.

## What This Shows

- Google Ads campaign planning
- Paid search budget logic
- Keyword grouping
- KPI thinking
- Landing page alignment
- Ecommerce performance marketing

## Main Features

- Campaign input form
- Daily budget calculation
- Target conversion and ROAS calculation
- Campaign budget split
- Keyword group generator
- Ad copy bank
- Landing page priority checklist

## Tech Stack

- React
- JavaScript
- Vite
- CSS

## Run Locally

```bash
npm install
npm run dev
```
