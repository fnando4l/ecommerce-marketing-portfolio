# Google Ads Campaign + Landing Page Plan

A React portfolio dashboard that shows how to plan a Google Ads campaign for an ecommerce product, connect keyword intent to ad groups, and align the landing page to conversion goals.

This project is built for paid media associate, digital marketing coordinator, Google Ads associate, and growth marketing roles.

## What This Shows

- Google Ads campaign structure
- Keyword grouping
- Search intent thinking
- Ad copy planning
- Landing page conversion planning
- Budget and KPI logic
- Reporting dashboard thinking

## Tech Stack

- React
- JavaScript
- Vite
- CSS
