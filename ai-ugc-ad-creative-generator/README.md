# AI UGC Ad Creative Generator

A React tool that turns an ecommerce creative brief into UGC hooks, short-form video script sections, static ad concepts, and a creative testing matrix.

The user enters product, target customer, main problem, product promise, and platform. The app generates ad creative assets for TikTok, Meta, and ecommerce campaigns.

## What This Shows

- UGC ad strategy
- Static ad concept development
- AI-assisted creative workflow
- Direct-response hooks
- Creative testing organization
- Ecommerce ad messaging

## Main Features

- Creative brief input form
- UGC hook generator
- Short-form script structure
- Static ad concept generator
- Creative testing matrix
- Interactive output tabs

## Tech Stack

- React
- JavaScript
- Vite
- CSS

## Run Locally

```bash
npm install
npm run dev
```
