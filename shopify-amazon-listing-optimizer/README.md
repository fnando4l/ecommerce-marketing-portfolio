# Shopify + Amazon Listing Optimizer

A React tool that turns product details into ecommerce listing assets for Shopify and Amazon.

The user enters a product name, category, audience, benefits, and price. The app generates Shopify product page copy, Amazon listing bullets, SEO keyword ideas, an optimization checklist, and a listing score.

## What This Shows

- Ecommerce listing optimization
- Shopify product page thinking
- Amazon marketplace copy structure
- Product positioning
- SEO keyword planning
- Conversion-focused customer journey thinking

## Main Features

- Product input form
- Shopify product page copy output
- Amazon title and bullet output
- SEO keyword suggestions
- Listing score
- Optimization checklist

## Tech Stack

- React
- JavaScript
- Vite
- CSS

## Run Locally

```bash
npm install
npm run dev
```
